# MacBook AI — Локальний AI-асистент

Цей вебзастосунок створено за допомогою фреймворку **Streamlit** для локальної взаємодії з мовними моделями через **Ollama**. Він повністю працює на вашому пристрої без використання інтернету.

## 🛠 Вимоги до системи

1. Встановлений Python 3.10+
2. Встановлена [Ollama](https://ollama.com/)
3. Завантажені моделі `llama3.1` та `llama3.2` в Ollama.

## 🚀 Як запустити застосунок

**Крок 1. Запустіть Ollama та завантажте моделі (якщо ще не зробили цього):**
Відкрийте термінал та виконайте команди:
```bash
ollama run llama3.1
ollama run llama3.2
```

**Крок 2. Встановіть необхідні Python-бібліотеки:**
У терміналі в папці з проєктом виконайте:
```bash
pip install streamlit openai
```

**Крок 3. Запустіть вебзастосунок:**
У терміналі виконайте:
```bash
streamlit run app.py
```

Після цього застосунок автоматично відкриється у вашому браузері (зазвичай за адресою `http://localhost:8501`).

## ⚙️ Можливості застосунку
* **Перемикання моделей:** Обирайте між швидкою `llama3.2` (3B) та розумною `llama3.1` (8B) просто під час діалогу.
* **Налаштування температури:** Регулюйте креативність відповідей повзунком.
* **Контроль токенів:** Встановлюйте ліміт довжини відповіді.
* **Історія чату:** Застосунок запам'ятовує контекст розмови в межах поточної сесії.
